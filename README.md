# AstroCheck Pro (Streamlit)

Εφαρμογή ελέγχου Astrodienst Data Sheet και δημιουργίας πλήρους εντολής/Word με οδηγίες v5.3, καθαρό οδηγό ύφους και χωριστή προαιρετική υπηρεσία επαγγελματικού προσανατολισμού.

## Εκτέλεση

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

## Ροή

1. Ανέβασμα μόνο του νέου Astrodienst PDF. Οι οδηγίες v5.3 και ο καθαρός οδηγός ύφους φορτώνονται αυτόματα.
2. Ανάγνωση πλανητών, ακμών, Οίκων, ανάδρομης κίνησης και πίνακα όψεων.
3. Υποχρεωτική οπτική επιβεβαίωση τετραγώνων/αντιθέσεων.
4. Συμπλήρωση προσωπικού πλαισίου και γλώσσας.
5. Λήψη master prompt ή προαιρετική αυτόματη συγγραφή με προσωπικό OpenAI API key.
6. Λήψη ελεγμένου τεχνικού Word.
7. Ανέβασμα της ανθρώπινης αναδιατύπωσης και δεύτερος μηχανικός έλεγχος πριν από την τελική λήψη.
8. Προαιρετικά, επιλογή στην καρτέλα 7 μεταξύ παιδιού/εφήβου και ενήλικα, χωρίς συλλογή πρόσθετων ψυχολογικών, σχολικών, επαγγελματικών ή οικονομικών δεδομένων. Δημιουργείται χωριστή εντολή αποκλειστικά από τον ελεγμένο χάρτη και ελέγχεται το αποτέλεσμα.

Ο επαγγελματικός προσανατολισμός είναι χωριστή, προαιρετική υπηρεσία. Υπάρχουν διαφορετικές δεσμευτικές εντολές για παιδί/έφηβο και για ενήλικα σε αλλαγή καριέρας. Δεν προστίθεται αυτόματα στη βασική ανάλυση 12 Οίκων.

## Σημαντικό

Η εφαρμογή δεν αντιμετωπίζει την αστρολογία ως επιστημονική ή ψυχολογική διάγνωση. Η Θεωρία των Μοιρών χρησιμοποιείται μόνο συμπληρωματικά. Η τελική ανάλυση πρέπει να περνά ανθρώπινο μαθηματικό, γλωσσικό και οπτικό έλεγχο.

Το ChatGPT ή το Claude πραγματοποιεί μόνο αυτοέλεγχο. Ο πραγματικός validator εκτελείται αποκλειστικά μέσα στην εφαρμογή, μετά την επιστροφή και τη μεταφόρτωση του παραγόμενου Word.
